# MeshLib 模块文档

本文档描述 `booltron/source/lib/meshlib.py` 中网格处理相关函数的作用。

---

## 模块概述

`meshlib` 提供网格预处理和验证功能，主要用于：
- 布尔运算前的网格清理
- 重叠检测
- 流形验证

依赖库：
- `bmesh`: Blender 网格编辑 API
- `bvhtree`: 空间加速结构，用于碰撞检测

---

## 1. `_delete_loose(bm: bmesh.types.BMesh)`

**内部函数** - 删除孤立顶点（无面连接的顶点）。

### 入参

| 参数 | 类型 | 描述 |
|------|------|------|
| `bm` | `bmesh.types.BMesh` | BMesh 对象 |

### 执行步骤

1. 遍历 BMesh 中所有顶点
2. 检查每个顶点是否满足删除条件：
   - `v.is_wire`: 顶点仅属于线段（无面）
   - `not v.link_edges`: 顶点无任何边连接
3. 若满足条件，从 BMesh 中移除该顶点

### 输出

无返回值，直接修改传入的 BMesh 对象。

### 图示

```
删除前:                    删除后:
    •  (孤立点)
   /|\                       /|\
  / | \                     / | \
 •--•--•                   •--•--•
    |                          |
    • (线段顶点)
```

## 2. `prepare(obs, merge_distance, dissolve_distance, check, select=False)`

**核心函数** - 预处理网格，为布尔运算做准备。

### 入参

| 参数 | 类型 | 描述 |
|------|------|------|
| `obs` | `list[Object]` | 要处理的对象列表 |
| `merge_distance` | `float` | 顶点合并距离阈值 |
| `dissolve_distance` | `float` | 退化边溶解距离阈值 |
| `check` | `bool` | 是否检查非流形几何 |
| `select` | `bool` | 是否选中所有面（默认 `False`） |

### 执行步骤

对每个对象执行以下操作：

```
┌─────────────────────────────────────────────────────────────┐
│  1. 创建 BMesh                                              │
│     bm = bmesh.new()                                        │
│     bm.from_mesh(ob.data)                                   │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  2. 合并重叠顶点 (Remove Doubles)                           │
│     bmesh.ops.remove_doubles(bm, verts, dist=merge_distance)│
│                                                             │
│     距离 < merge_distance 的顶点会被合并为一个              │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  3. 溶解退化边 (Dissolve Degenerate)                        │
│     bmesh.ops.dissolve_degenerate(bm, edges, dist)          │
│                                                             │
│     移除长度 < dissolve_distance 的边                       │
│     防止零面积三角形导致布尔运算失败                        │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  4. 删除孤立顶点                                            │
│     _delete_loose(bm)                                       │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  5. 填充孔洞                                                │
│     bmesh.ops.holes_fill(bm, edges=bm.edges)               │
│                                                             │
│     自动填充网格中的开放边界                                │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  6. 非流形检查 (可选)                                       │
│     if check:                                               │
│         遍历所有边，检查 e.is_manifold                      │
│         若发现非流形边 → 返回 True（失败）                  │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  7. 设置面选择状态                                          │
│     for f in bm.faces: f.select = select                   │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  8. 写回网格数据                                            │
│     bm.to_mesh(me)                                         │
│     bm.free()                                              │
└─────────────────────────────────────────────────────────────┘
```

### 输出

| 返回值 | 类型 | 描述 |
|--------|------|------|
| `True` | `bool` | 检测到非流形几何（处理失败） |
| `False` | `bool` | 所有对象处理成功 |

### 什么是流形 (Manifold)？

```
流形边（正常）:          非流形边（问题）:

  ┌───┐                    ┌───┐
  │   │                    │   │╲
  │   │  ← 边被2个面共享   │   │ ╲  ← 边被3个面共享
  └───┘                    └───┘  ╲
                                   ╲
```

流形网格的每条边**恰好被 2 个面共享**，这是布尔运算的前提条件。

## 3. `detect_overlap(obs: list[Object])`

**功能** - 检测多个对象之间是否存在几何重叠。

### 入参

| 参数 | 类型 | 描述 |
|------|------|------|
| `obs` | `list[Object]` | 要检测的对象列表 |

### 执行步骤

```
┌─────────────────────────────────────────────────────────────┐
│  1. 获取属性和依赖图                                        │
│     props = bpy.context.window_manager.booltron.destructive │
│     depsgraph = bpy.context.evaluated_depsgraph_get()       │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  2. 创建统一 BMesh                                          │
│     bm = bmesh.new()                                        │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  3. 合并所有对象的网格（世界坐标系）                        │
│     for ob in obs:                                          │
│         ob_eval = ob.evaluated_get(depsgraph)  # 应用修改器│
│         me = ob_eval.to_mesh()                              │
│         me.transform(ob.matrix_world)  # 转换到世界坐标    │
│         bm.from_mesh(me)                                    │
│         ob_eval.to_mesh_clear()                             │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  4. 合并重叠顶点                                            │
│     bmesh.ops.remove_doubles(bm, verts, dist=merge_distance)│
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  5. 构建 BVH 树并检测自相交                                 │
│     tree = BVHTree.FromBMesh(bm, epsilon=0.00001)          │
│     overlap = tree.overlap(tree)                            │
│                                                             │
│     BVH 树是空间划分结构，可快速检测三角形重叠              │
│     tree.overlap(tree) 检测树与自身的重叠                   │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  6. 清理并返回结果                                          │
│     bm.free()                                               │
│     return bool(overlap)                                    │
└─────────────────────────────────────────────────────────────┘
```

### 输出

| 返回值 | 类型 | 描述 |
|--------|------|------|
| `True` | `bool` | 对象之间存在重叠 |
| `False` | `bool` | 对象之间无重叠 |

### 为什么要检测重叠？

在 `destructive/__init__.py` 的 `invoke()` 中使用：

```python
if len(obs) > 2 and self.mode != "SLICE":
    self.is_overlap = meshlib.detect_overlap(obs)
```

**重叠时**（`is_overlap=True`）：
- 逐个应用布尔运算
- 保持正确的重叠处理

**不重叠时**（`is_overlap=False`）：
- 先将所有次级对象 Join 为一个
- 一次性执行布尔运算（更高效）

```
重叠情况:                  不重叠情况:
   ┌───┐                    ┌───┐     ┌───┐
   │ A │                    │ A │     │ B │
   │ ┌─┴─┐                  └───┘     └───┘
   └─┤ B │
     └───┘                  可以先 Join 再布尔
   需要逐个处理
```

## 4. `is_nonmanifold(ob: Object)`

**功能** - 检查单个对象是否包含非流形几何。

### 入参

| 参数 | 类型 | 描述 |
|------|------|------|
| `ob` | `Object` | 要检查的对象 |

### 执行步骤

```
┌─────────────────────────────────────────────────────────────┐
│  1. 创建 BMesh 并加载网格数据                               │
│     bm = bmesh.new()                                        │
│     bm.from_mesh(ob.data)                                   │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  2. 遍历所有边检查流形性                                    │
│     for e in bm.edges:                                      │
│         if not e.is_manifold:                               │
│             bm.free()                                       │
│             return True  # 发现非流形                       │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  3. 清理并返回                                              │
│     bm.free()                                               │
│     return False  # 网格是流形的                            │
└─────────────────────────────────────────────────────────────┘
```

### 输出

| 返回值 | 类型 | 描述 |
|--------|------|------|
| `True` | `bool` | 网格包含非流形边 |
| `False` | `bool` | 网格是流形的 |

### 使用场景

在布尔运算完成后验证结果：

```python
# destructive/__init__.py 第 100-101 行
if meshlib.is_nonmanifold(ob1):
    self.report({"ERROR"}, "Boolean operation result is non-manifold")
```

## 函数调用关系

```
destructive.execute()
       │
       ├──→ prepare(ob1, ...)        # 预处理主对象
       │         │
       │         └──→ _delete_loose()
       │
       ├──→ prepare(obs, ...)        # 预处理次级对象
       │         │
       │         └──→ _delete_loose()
       │
       ├──→ [执行布尔运算]
       │
       └──→ is_nonmanifold(ob1)      # 验证结果


destructive.invoke()
       │
       └──→ detect_overlap(obs)      # 检测次级对象重叠
```

## 关键概念总结

| 概念 | 说明 |
|------|------|
| **BMesh** | Blender 的可编辑网格数据结构，支持高效的几何操作 |
| **流形 (Manifold)** | 每条边恰好被 2 个面共享的网格，是布尔运算的前提 |
| **BVH 树** | 层次包围盒树，用于快速空间查询和碰撞检测 |
| **退化边** | 长度接近零的边，会导致布尔运算失败 |
| **孤立顶点** | 不属于任何面的顶点，应在运算前清理 |
